# Luna Arcana

Taro kortos, ritualai pagal Mėnulį, numerologija, sapnininkas ir taro pamokos lietuviškai. Įdiegiama kaip programėlė (PWA) ir veikia be interneto.

Laikinas talpinimas per GitHub Pages: paieškos sistemoms uždaryta (`robots.txt`, `noindex`), kol svetainė persikels į savo domeną.

Turinys ir kodas sugeneruoti iš darbinio projekto; statiniai puslapiai `lt/` kuriami generatoriumi.
